_Digital Tool Buying Platform_

Digital Tool Buying Platform is a modern web application where users can explore, compare, and purchase premium digital tools. It provides a smooth user experience with dynamic product listings, cart functionality, and responsive design.

Technologies Used:
React.js
JavaScript (ES6+)
Tailwind CSS
DaisyUI
JSON (for data handling)
React-Toastify
React Hooks

Key Features:
Dynamic Card Listing
Add to Cart System
Interactive UI and Navigation
