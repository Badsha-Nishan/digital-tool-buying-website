# 🛒 Digital Tool Buying Platform

A modern web application where users can explore, compare, and purchase premium digital tools.
This platform provides a smooth and interactive user experience with dynamic product listings, cart functionality, and responsive design.

---

## 🚀 Live Demo

👉 https://digital-tool.netlify.app

---

## 🛠️ Technologies Used

* ⚛️ React.js
* 🟨 JavaScript (ES6+)
* 🎨 Tailwind CSS
* 🌼 DaisyUI
* 📦 JSON (for data handling)
* 🔔 React-Toastify
* 🪝 React Hooks

---

## ✨ Key Features

* 🛍️ Dynamic product card listing
* ➕ Add to cart functionality
* 🔄 Interactive UI & smooth navigation
* 📱 Fully responsive design
* 🔔 Toast notifications for user actions

---

## 📂 Project Structure

* `src/components` → Reusable UI components
* `src/pages` → Application pages
* `src/data` → JSON data files
* `src/hooks` → Custom React hooks
